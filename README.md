## 机房学生签到系统（Flask）

### 运行方式

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

打开：
- 学生端：`http://localhost:5000/student`
- 教师端登录：`http://localhost:5000/teacher/login`

### 功能
- 学生输入姓名签到，自动提示名单，验证姓名合法性。
- 学生端提交做了防连点，后端也有去重兜底，避免重复签到。
- 签到记录统一使用客户端 IP，避免主机名反查不稳定带来的误差。
- 教师端需要登录（初始密码 `abc123`），支持修改密码和退出登录。
- 教师端实时查看签到状态、已到/未到统计、签到名单（已签到按时间先后置顶，未签到在后）。
- 支持签到时间段控制、重置签到。
- 支持 Excel 导入学生名单、导出全名单签到记录（未签到时间为空）。
- 教师端支持一键清空当前名单（同时清空签到记录）。
- 新增座位情况页面（8×8 座位图）：按已签到学生 IP 最后一段匹配座位编号并显示姓名，过道列加粗。
